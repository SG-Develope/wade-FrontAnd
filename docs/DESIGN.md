## 확장 · 화면/진입 구조 (v6)

기존 4개 탭은 그대로 유지하고, 회원·관리자·문의 화면은 **탭이 아닌 헤더/개별 진입**으로 둔다.

### 하단(또는 상단) 탭 — 서비스 핵심

| 탭 | 경로 | 아이콘 | 로그인 필요 |
|---|---|---|---|
| 실시간 현황 | `/dashboard` | 🌊 | X |
| 수위 추이 | `/trends` | 📈 | X |
| 여가 지도 | `/leisure` | 🗺️ | X |
| 날씨·레이더 | `/weather` | 🌤️ | X |

### 헤더/계정 진입 — 회원 영역

| 화면 | 경로 | 진입 위치 | 로그인 필요 |
|---|---|---|---|
| 로그인 | `/login` | 헤더 우측 "로그인" | X |
| 마이페이지 | `/mypage` | 헤더 우측 프로필 | O |
| 내 문의 목록 | `/mypage/inquiries` | 마이페이지 내부 | O |
| 문의 작성 | `/inquiries/new` | 마이페이지·상세 | O |
| 관리자 대시보드 | `/admin` | 관리자만 노출 | O (ADMIN) |

> 헤더는 비로그인 시 "로그인" 버튼, 로그인 시 프로필(닉네임/아바타)로 분기. `role=ADMIN`일 때만 관리자 진입 노출.

## 확장 · 폼 & 버튼 (로그인·회원가입·문의)

기존 문서에 없던 폼 규칙. 브랜드 컬러(`river`) 재사용.

### 버튼

| 종류 | 배경 | 텍스트 | 용도 |
|---|---|---|---|
| Primary | `#1D9E75` (river) | `#FFFFFF` | 로그인, 제출, 확인 |
| Secondary | `#FFFFFF` / border `#EDE8E0` | `#2D3A1F` | 취소, 보조 액션 |
| Kakao | `#FEE500` | `#191600` | 카카오 로그인 전용 |
| Danger | `#E24B4A` | `#FFFFFF` | 삭제 |
| Disabled | `#EDE8E0` (pebble) | `#8A9A7A` (moss) | 비활성 |

- 높이 44px, radius 10px, 굵기 600. 전체 폭 버튼은 폼 하단에 배치.

### 입력 필드

| 상태 | 보더 | 배경 | 설명 |
|---|---|---|---|
| 기본 | `#EDE8E0` (pebble) | `#FFFFFF` | radius 10px, padding 12px |
| 포커스 | `#1D9E75` (river) | `#FFFFFF` | 보더 강조 |
| 에러 | `#E24B4A` | `#FEEEEE` | 하단에 에러 메시지(`#A32D2D`, 11px) |
| 라벨 | — | — | `#2D3A1F` 13px 600, 필드 상단 |

- 유효성 에러는 색상 + 텍스트 병행(디자인 원칙 준수).

## 확장 · 여가 지도 표현 규칙

관측소 마커(기존)와 구분되는 **여가 장소/코스** 표현.

### 장소 마커 (점)

| 종류 | 아이콘 | 마커 색 |
|---|---|---|
| 캠핑장 | 🏕️ | `#1D9E75` (river) |
| 낚시터 | 🎣 | `#5DCAA5` (river-mid) |
| (기타 지점) | 📍 | `#8A9A7A` (moss) |

### 코스 (선 · Polyline)

| 종류 | 선 색 | 굵기 | 스타일 |
|---|---|---|---|
| 자전거길 | `#2F80ED` | 5px | 실선, opacity 0.85 |
| 산책로 | `#9B59B6` | 4px | 실선, opacity 0.85 |

- 선택된 코스는 굵기 +2px, opacity 1.0으로 강조.
- 지도 우하단에 **범례(legend)** 고정: 종류별 색·아이콘 표기.
- 장소 안전 상태(연결 관측소 수위)는 기존 수위 4단계 색을 마커 테두리/배지로 병기.
